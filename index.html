외부 링크 등록

Google Drive 공유 링크 사용법
  1. Drive에서 파일/폴더 우클릭 → 공유
  2. 링크 보기를 "링크가 있는 모든 사용자"로 변경
  3. 링크 복사 후 아래 붙여넣기
예: https://drive.google.com/file/d/1aBcDe.../view
Dropbox 공유 링크 사용법
  1. Dropbox에서 파일 우클릭 → 공유 또는 링크 복사
  2. 공유 링크를 아래 붙여넣기
  3. 직접 열기는 dl=0 → dl=1 변경으로 다운로드 가능
예: https://www.dropbox.com/s/abc123/파일명.pdf
기타 공개 링크
  1. OneDrive, Box, Notion, GitHub 등 외부 공개 링크 등록 가능
  2. 링크는 공개(public) 접근 가능해야 합니다
